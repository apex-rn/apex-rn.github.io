Privacy Policy

Last updated: 2026-11-24

CC Office Uploader is an internal tool used only by the owner of the Compound Chronicle YouTube channel. It uses YouTube API Services to upload videos, set thumbnails, add videos to playlists and read basic channel statistics for that one channel.

Data accessed: the OAuth token of the channel owner and the channel's own video and statistics data. No data from any other person is collected.

Storage: the OAuth token is stored only on the owner's private server and computer. Data is not sold, shared or transferred to any third party.

Deletion: the owner can revoke access at any time at Google security settings; stored tokens are then deleted.

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact: via the Compound Chronicle channel page.
